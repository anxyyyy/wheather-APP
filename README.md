
# Weatherly

Modern weather application with real-time weather, 5-day forecast, geolocation and dark mode.

## Features

- Real-time weather
- 5-day forecast
- Geolocation support
- Search history
- Dark mode
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeather API
